## Captured automatically

ClaudeSec captures [Codex](https://github.com/openai/codex) sessions with **no setup**. Codex writes a transcript per session to:

```
~/.codex/sessions/**/*.jsonl
```

Once ClaudeSec is running (`npm run dev`), the [transcript watcher](/explanation/watcher) tails those files live. No environment variables, no flags, no restart.

---

## What ClaudeSec extracts

The watcher understands Codex's record format and maps:

| Codex record | Becomes |
|--------------|---------|
| `function_call` / `tool_call` / `local_shell_call` | A tool span (named by `name` / `tool_name`) |
| `command` / `arguments` | Span attributes the detection rules match against |
| `function_call_output` / `local_shell_call_output` | The span's end / duration |
| `session_id` | Trace ID |

Shell commands Codex runs flow straight into the [Command Audit](/review/command-audit) trail and are scored by the [183 threat rules](/security/rules) like any other span.

---

## Troubleshooting

1. Confirm the service is running: `claudesec status`.
2. Confirm transcripts exist: `ls ~/.codex/sessions/`.
3. Only new activity is captured by default — set `CLAUDESEC_BACKFILL=1` to import history.
