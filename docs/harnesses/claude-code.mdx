## Captured automatically

[Claude Code](https://docs.anthropic.com/en/docs/claude-code) is Anthropic's official command-line agent. ClaudeSec captures it with **no setup at all**.

Claude Code writes a full session transcript for every conversation to:

```
~/.claude/projects/**/*.jsonl
```

Once ClaudeSec is running (`npm run dev`), the [transcript watcher](/explanation/watcher) tails those files live. The moment Claude Code reads a file, runs a command, or makes a model request, the corresponding span appears in your dashboard — including sessions that were already running before you started it.

You do **not** set `CLAUDE_CODE_ENABLE_TELEMETRY`, `OTEL_*`, or anything else. The installer actually *removes* any legacy ClaudeSec OTEL config it finds, because the watcher needs none.

## What ClaudeSec extracts

From each transcript record, the watcher derives:

| Field | Source |
|-------|--------|
| Tool name | `message.content[].tool_use.name` (e.g. `Bash`, `Read`, `Edit`, `Write`, MCP tools, skills) |
| Tool input | `tool_use.input` — surfaced as the span's `reason` summary and full attributes |
| Duration | Paired `tool_use` → `tool_result` records |
| Model & tokens | `message.model` + `message.usage` (emitted as a `llm_request` span for the Cost view) |
| Working dir / branch | `cwd`, `gitBranch` |
| Session | `sessionId` → trace ID |

Cache-read and cache-creation tokens are folded into a billed-input estimate so the [Cost view](/cost/costs) reflects real API-equivalent spend.

## Threat patterns to watch for

| Scenario | Severity | Example rule |
|----------|----------|------|
| Agent runs `rm -rf /some/path` | HIGH | Recursive root deletion |
| Agent reads `~/.ssh/id_rsa` or a `.pem` | HIGH | SSH private-key access |
| Prompt contains "ignore previous instructions" | HIGH | Prompt injection: instruction override |
| Agent reads a `.env` file | MEDIUM | Dotenv file access |
| Agent uses `sudo` | LOW | Sudo usage |

See the full library on the [Security Rules](/security/rules) page.

## Troubleshooting

**No Claude Code activity appears**

1. Confirm the service is running: `node cli/init.mjs status`.
2. Confirm transcripts exist: `ls ~/.claude/projects/`.
3. By default only **new** activity is captured. To import history, restart with `CLAUDESEC_BACKFILL=1`.
4. Make sure the watcher is enabled (it is unless `CLAUDESEC_WATCH=0`).
