ClaudeSec is zero-config. You do not set any environment variables, edit your shell profile, or restart your agents. One command installs a background service and opens the dashboard.

## Prerequisites

- **Node.js 18+** (Node 20 LTS recommended)
- At least one supported agent on your machine — [Claude Code](/harnesses/claude-code), [GitHub Copilot CLI](/harnesses/copilot), or [Codex](/harnesses/codex)

<Note>
  `better-sqlite3` builds a native module on install. If you hit a build error, install the Xcode Command Line Tools (macOS) or `build-essential` (Linux) and try again.
</Note>

---

## Step 1 — Run it

```bash
npx claudesec
```

This single command:

1. Removes any legacy OTEL environment config left over from older setups.
2. Installs a user-level background service (launchd on macOS, systemd user service on Linux, a Scheduled Task on Windows).
3. Starts tailing every Claude Code, Copilot CLI, and Codex session on your machine.
4. Opens the dashboard at **http://localhost:3000**.

Because your agents already write transcripts to disk, the dashboard fills with **real, live activity immediately** — including sessions that were running before you installed.

---

## Step 2 — Look around

Open [http://localhost:3000](http://localhost:3000) (it opens automatically). Within seconds of any agent action you'll see:

- A session row per trace, tagged with the harness that produced it.
- Spans appearing in the **Timeline** as colored bars, with live durations.
- **Alert** counts incrementing whenever a detection rule matches.

Take the [dashboard tour](/observe/timeline) to learn each screen.

---

## Step 3 — Check status from the terminal

```bash
claudesec status      # server health, span/session/alert counts, uptime
claudesec tail        # stream new spans live in your terminal
claudesec processes   # list running agent processes
```

See the [CLI reference](/reference/cli) for every command.

---

## Stopping {#stopping}

Stop and remove the background service at any time:

```bash
claudesec stop
```

Your data in `~/.claudesec` / `spans.db` is left untouched. To wipe stored data, run `claudesec reset`.

---

## Running from source

```bash
git clone https://github.com/aanjaneyasinghdhoni/ClaudeSec.git
cd ClaudeSec
npm install
npx claudesec        # or: npm run dev   (foreground, no background service)
```

`npm run dev` runs the Express backend with Vite HMR in the foreground on port 3000 — handy for development.

---

## Platform support

| Platform | Background service | Status |
|---|---|---|
| macOS | launchd LaunchAgent | **Verified** |
| Linux | systemd user service | Experimental |
| Windows | Scheduled Task (at logon) | Experimental |

The watcher and dashboard run anywhere Node ≥ 18 runs; only the auto-start *service* layer is platform-specific. On any platform you can always run the foreground server with `npm run dev`.
