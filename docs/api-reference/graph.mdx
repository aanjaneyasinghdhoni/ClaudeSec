## Endpoint

```
GET /api/graph
GET /api/graph?session={traceId}
GET /api/graph?repo=…&sev=…&harness=…&t=…&q=…
```

Returns node and edge data for the span dependency graph. This is a headless API endpoint — there is no graph tab in the dashboard UI. Use this endpoint for programmatic access, custom integrations, or to feed data into external visualization tools.

<Note>
  All nodes are returned with `position: { x: 0, y: 0 }`. The server does not compute layout coordinates — run your own layout engine (e.g. Dagre or the built-in React Flow layout) client-side.
</Note>

---

## Query parameters

The filter parameter names intentionally match the URL keys the dashboard's own filter state
uses, so a filtered view can forward its state to this route almost verbatim. `session` is
mutually exclusive with the rest — a session-scoped graph loads that trace in full and ignores
the other filters.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `session` | string | No | Filter graph to spans belonging to a specific `traceId`. Loads the full session (not subject to the window below). |
| `repo` | string | No | Comma-separated list of repo values to match (as scrubbed and stored, e.g. `/Users/***/myproject`) |
| `sev` | string | No | Comma-separated severities: `none`, `low`, `medium`, `high`, `critical`. Unrecognized values are dropped |
| `harness` | string | No | Comma-separated harness IDs, e.g. `claude-code,codex` |
| `t` | string | No | Time window: `1h`, `24h`, or `7d`. Any other value is ignored (no time filter) |
| `q` | string | No | Full-text search over span content, same term-splitting behavior as [`/api/spans`](/api-reference/spans) |

When no filter is given (bare `GET /api/graph`), the response is the most-recent `CLAUDESEC_GRAPH_LIMIT` spans across all sessions (default `2000`) — see [Data retention](/explanation/retention#the-graph-window-vs-your-full-history). Filtered queries apply the same limit to the filtered set.

### Windowing metadata

Present on every response (older consumers can ignore these fields — they're additive):

| Field | Type | Description |
|-------|------|-------------|
| `windowed` | boolean | `true` when there are more matching spans than were returned — the graph is showing only the most-recent `limit` |
| `shown` | number | Spans actually returned in this response |
| `total` | number | Spans matching the filter in total (ignoring the window). For a `session`-scoped graph this equals `shown`, since a single session always loads in full |
| `limit` | number | The window size applied — `CLAUDESEC_GRAPH_LIMIT` (default `2000`) |

Older data is never deleted by windowing — it's still reachable through **Search** and **Sessions**. Narrow with `repo`/`sev`/`harness`/`t`/`q` to bring a specific slice back within the window.

### Node object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Span ID (or harness ID for root nodes) |
| `data.label` | string | Display name shown in the graph |
| `data.isRoot` | boolean | `true` for harness root nodes |
| `data.harnessColor` | string | Hex color for root nodes |
| `data.attributes` | object | Parsed span attributes (key-value pairs) |
| `data.severity` | string | `none`, `low`, `medium`, or `high` |
| `data.isMalicious` | boolean | `true` if severity is not `none` |
| `data.protocol` | string | Protocol extracted from span attributes (default: `"HTTPS"`) |
| `data.reason` | string | Reason string from span attributes (default: `"Processing step"`) |
| `data.harness` | string | Harness ID (e.g., `"claude-code"`) |
| `data.traceId` | string | Session trace ID |
| `data.startNano` | string | Start timestamp in nanoseconds |
| `data.endNano` | string | End timestamp in nanoseconds |
| `position` | object | `{x, y}` coordinates — always `{ "x": 0, "y": 0 }` (no server-side layout) |
| `style` | object | React Flow inline style. Threat spans get a colored border (see below); clean (`none`) spans get a neutral elevated style. |

### Severity styles

| Severity | Background | Border |
|----------|-----------|--------|
| `none` | `var(--cs-bg-elevated)` | `1px solid var(--cs-border-soft)` |
| `low` | `#fefce8` | `2px solid #eab308` |
| `medium` | `#fff7ed` | `2px solid #f97316` |
| `high` | `#fee2e2` | `2px solid #ef4444` |

Threat spans (`low`/`medium`/`high`) use a `#1e293b` text color; clean (`none`) spans use the theme variables shown above.

### Edge object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `"e-{parentId}-{spanId}"` |
| `source` | string | Parent span ID (or harness root ID) |
| `target` | string | Child span ID |
| `label` | string | Protocol label |
| `animated` | boolean | Always `true` |
| `style` | object | Colored stroke for threat spans; empty for clean spans |

## Examples

### Fetch the full graph

```bash
curl http://localhost:3000/api/graph
```

### Fetch a session-scoped graph

```bash
curl "http://localhost:3000/api/graph?session=4bf92f3577b34da6a3ce929d0e0e4736"
```

### Fetch a filtered graph

```bash
curl "http://localhost:3000/api/graph?sev=high,critical&harness=claude-code&t=24h"
```

### JavaScript (fetch)

```javascript
const response = await fetch('http://localhost:3000/api/graph');
const { nodes, edges } = await response.json();
// Pass directly to React Flow
```

      "type": "input"

  ],

  "windowed": false,
  "shown": 0,
